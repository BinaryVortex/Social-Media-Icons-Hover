# Social Media Icons Hover

Social Media Icons Hover is a small, lightweight demo built with plain HTML and CSS that showcases animated hover effects for social media icons. It's perfect as a simple UI snippet to copy into personal projects, landing pages, or portfolios.

![Demo Screenshot](./Screenshot%202024-07-03%20101444.png)

## Demo
Open `index.html` in your browser to see the effect. No build tools or dependencies required — just static files.

## Features
- Pure HTML & CSS (no JavaScript)
- Smooth hover animations for social icons
- Easy to copy, customize and drop into other projects

## Files
- `index.html` — demo markup
- `style.css` — styles and hover effects
- `Screenshot 2024-07-03 101444.png` — demo screenshot used in this README

## Usage
1. Clone or download the repository.
2. Open `index.html` in any modern browser.

Optional: Serve with a static server (e.g., `live-server` or `python -m http.server`) for local development.

## Customization Tips
- Edit `style.css` to change colors, sizes and animation timing.
- Replace the icon elements or swap in SVGs for sharper scaling.
